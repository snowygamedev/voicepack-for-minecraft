# VoicePack for Minecraft

A desktop app for creating Minecraft resource packs with your own recorded sounds.

> Not affiliated with, endorsed by, or associated with Mojang or Microsoft. No official Minecraft files are included.

## Features

- 🎙️ Record your own sounds with your mic and map them to in-game sound events
- 🎨 Build and edit resource packs
- 📦 Export as a ready-to-install pack

## Install

```bash
git clone https://github.com/yourname/voicepack-for-minecraft.git
cd voicepack-for-minecraft
npm install
npm run dev
```

## Usage

1. Open the app and create a new pack
2. Pick a sound event (e.g. `entity.zombie.hurt`)
3. Record your replacement sound
4. Export and drop the pack into your `resourcepacks` folder
